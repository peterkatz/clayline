Clayline

SVG centerlines and meshes in. Audited G-code for clay paste printers out.

Download for Mac

Apple-silicon Macs, macOS 14 or newer. Signed and notarized, so it opens without warnings. Unzip and drag Clayline to Applications. Free, open source under GPL-3.0.

What it does

  • Tiles mode: draw a pattern as stroked centerlines in any SVG editor, and Clayline plans one continuous coil path per layer, welding strokes, hopping across kiss points, and laying pages out across the bed.
  • Weave mode: open a mesh such as a tumbler or vessel, and Clayline slices it into a single unbroken thread with controllable ribs, interiors, and print range.
  • Drape or calibrated Z: keep the nozzle high and let the coil fall into place, or print layer by layer at measured heights.
  • Audited output: every file passes an independent lint against the printer profile before it reaches you, and the header records every parameter the job used.

Built for the PotterBot 10 XL and shaped around real prints. The engine runs entirely on your Mac: no account, no cloud, no network.

G-code moves real machinery. A lint pass means the file is consistent with the selected profile, not that your printer, clay, nozzle, or clearances are safe. Read the G-code, keep the emergency stop reachable, and stay with the printer.

Source and contributing

The code lives at github.com/peterkatz/clayline, with a Python engine, a local web studio, and a native macOS shell. Issues and pull requests are welcome; contributors sign a short agreement described in the repository's CONTRIBUTING file.
